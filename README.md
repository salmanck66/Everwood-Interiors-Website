# Everwood Interiors — Client Website

Marketing website for **Everwood Interiors**, an interior design and furniture studio in Areekode, Kerala. I designed and built it for the client, and it's live in production.

## Goals

- Look as premium as the studio's work, and load fast on mobile data
- Present the portfolio and fixed-price packages clearly
- Turn visitors into **WhatsApp conversations** in one tap

## What I built

- **Sections:** hero with key stats, project gallery, services, three tiered packages (Essential, Signature, Luxury), testimonials, about and contact
- **WhatsApp-first conversion.** Every call to action opens WhatsApp with a pre-filled message naming the specific package or service, so the studio knows exactly what the lead wants. A floating WhatsApp/call button stays on screen.
- **Mobile-first responsive layout** with breakpoints at 600 / 1024 / 1280 px
- **Scroll-reveal animations** using `IntersectionObserver` (no animation library)
- **Typography:** Fraunces + Plus Jakarta Sans, with a warm, material-inspired palette to match the brand
- **No framework, no build step.** It's one HTML file, so the client can host it anywhere and it loads quickly

## Run locally

```bash
git clone https://github.com/salmanck66/Everwood-Interiors-Website.git
cd Everwood-Interiors-Website
npx serve .      # or just open index.html
```
